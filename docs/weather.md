# 天气：带不带伞、穿什么，和每天早上的今日提醒

插件 `weather` 是助理Bot（个人助理）的一部分：它的贴图就是助理，所以 App 不把它当成单独的 Bot，它的卡片排在助理Bot 页面的最前面。实现在 `backend/plugins/weather/`。

## 数据从哪来

- 天气预报来自 [Open-Meteo](https://open-meteo.com)：免费、不用账号和 key，按经纬度给出今明后三天的预报。后端每 2 小时读一次（任务 `plugin:weather:forecast`），启用插件时也读一次。只发经纬度，不发任何个人信息。
- 设置里填 `place`（卡片上显示的名字，默认「上海」）、`latitude`、`longitude`。没填经纬度时卡片会提示去填。

## 建议怎么算

数字和建议都由代码按固定规则算（`forecast.py`），不交给模型：

- **带伞**：当天降水概率 ≥ 50% 时「要带伞」，并写出白天（7–23 点）哪几个小时可能下雨；30–49% 时，或者概率虽低但预报全天有 ≥ 1 毫米的零星小雨（毛毛雨）时，「带把折叠伞」；否则「不用带伞」。
- **穿衣**：按体感温度（当天最高和最低体感的平均）分七档：≥ 28°C 短袖短裤；23–28 短袖或薄长袖；18–23 长袖衬衫或薄外套；13–18 外套或卫衣；8–13 毛衣加厚外套；3–8 棉服或羽绒服；更冷厚羽绒服、戴围巾手套。最高和最低气温差 ≥ 10°C 时加一句「早晚温差大，带件外套」。
- **防晒**：紫外线指数 ≥ 6。**风大**：最大风速 ≥ 38 公里/时。

## 今日提醒

每天早上（`brief_cron`，默认 6:30，任务 `plugin:weather:brief`）由 Agent 写一张不超过 260 字的「今日提醒」清单，格式固定（`prompts/weather_brief.md`）：「**天气**」（温度、带不带伞、穿什么）、「**课程**」（今天的每节课）、「**待办**」（今天截止的待办、作业、活动和请假），需要时再加「**注意**」（下雨撞上课，或数据看门狗的系统提醒合成一句；系统提醒不算待办）。每节一行概括加「- 」短条目。Agent 通过 MCP 读 `weather_forecast` 和当天的每日文件夹（`今天.md`、`课程.md` 等），用 `weather_brief_write` 写回；数字只能照抄。

默认先交给 **DeepSeek**（`brief_agent`，见 [deployment.md](deployment.md)「DeepSeek」），它失败时按设置里的顺序换 Claude Code、Codex。一天写一次，已经写过就不再写。

## 用在哪里

- **卡片**（助理Bot 页面最前）：今日提醒（写好以后）、「上海今天」（气温、天气、降水概率，`symbol` 是天气的 SF Symbol，App 画在卡片右上角）、出门提醒（伞、穿衣、防晒、风）、明天。读不到时有一张「天气没读到」说明原因。
- **每日文件夹**：`每日/<日期>/天气.md`，`今天.md` 分工里「助理Bot · 天气」一行。
- **MCP 工具**：`weather_forecast`（三天的预报和算好的建议）、`weather_brief_write`（写某一天的今日提醒）。

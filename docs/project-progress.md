# 项目进度（知识库Bot）

插件 `project_progress` 在知识库的页面上显示这个项目做到哪了。数字和文字分两处来：

- **提交和 PR**：插件自己从本机 git 仓库数，只读，5 分钟内的结果直接复用。配置 `repos` 列出要数的仓库（名字和路径），不填时只数后端所在的仓库。提交按作者日期分天，统计所有本地分支上不重复的提交，没合并的分支也算；PR 数是「Merge pull request #N」合并提交里不重复的 N。
- **工作线、接下来、里程碑**：读记忆目录里的一份 Markdown，默认 `Bots/知识库/项目进度.md`（配置 `progress_file` 可改）。每次打开页面都重新读，改了文件不用重启。

这份文件在知识库自己的角色目录里，所以有三种改法：在 Obsidian 里直接改；在 App 里让知识库改（她能读写自己目录下的文件）；或者让 Claude、GPT 在每轮工作结束时更新。

## 文件格式

只认下面三节，其余内容（标题、前言、别的小节）都忽略，可以随便写。

```markdown
# 项目进度

## 工作线

### DSH 插件版
- 状态：进行中
- 时间：2026-11-12 起
- 现在：三个插件各做完一到两轮
- 下一步：GPT 全做完后在桌面版试装

## 接下来
- [ ] 把最新 App 重装到 iPhone
- [x] 做一个项目看板

## 里程碑
- 2026-11-12 DSH 插件版开工
```

- **工作线**：每个 `###` 是一条，下面认 `状态`、`时间`、`现在`、`下一步` 四个字段，中文或英文冒号都行。卡片显示名字、「状态 · 时间」和「现在」。状态写「进行中」的工作线会出现在「开发天数」卡片的说明里。
- **接下来**：`- [ ]` 是还没做的，显示在卡片上，最多 8 条；`- [x]` 是做完的，不显示。不带方框的 `- ` 也当作没做。
- **里程碑**：`- YYYY-MM-DD 发生了什么`，卡片显示今天及以前最近的 5 条，日期以后的先不显示。

文件不存在时，这三张卡片换成一张说明在哪里建文件的卡片；文件超过 200 KB、不是 UTF-8 或路径不在记忆目录里时，卡片上直接说原因。
